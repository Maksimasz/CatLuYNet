# CatLu YNet 1.1.9 — порядок кнопок редактора плейлиста

## Изменения

- Кнопки редактора размещены в трёх фиксированных строках и больше не переносятся произвольно.
- В первой строке «Удалить весь плейлист» находится рядом с «Удалить».
- Во второй строке собраны скачивание выбранного MP3, скачивание всех MP3 и новая кнопка «Удалить MP3 с диска».
- «Закончить редактирование плейлиста» занимает всю ширину последней строки.
- Надписи выровнены по центру. При сужении окна шрифт уменьшается, размер окна ограничен рабочей областью экрана.
- Удаление MP3 требует подтверждения и сохраняет трек в плейлисте. Удалённый файл больше не используется для локального воспроизведения; при отсутствии другой локальной копии используется YouTube.
- Если удаляемый MP3 используется другим плейлистом, ссылки на этот файл очищаются и там. При удалении файла текущего трека воспроизведение останавливается.

## Проверка

- Release-сборка без предупреждений и ошибок; 196 регрессионных проверок.
- Проверены размещение кнопок, центрирование и размеры текста при ширине окна 500, 620 и 800 пикселей; проверена отрисовка редактора.
- Удаление MP3 и сохранение записи плейлиста проверены на временных тестовых файлах.
- Ручная установка и живое воспроизведение этой версии не проверены.

## Установка

`CatLuYNet-1.1.9-Setup.exe` — установщик Windows x64 со встроенным .NET.
`CatLuYNet-1.1.9-win-x64.zip` — portable архив.
Включены yt-dlp, FFmpeg и FFprobe. Личные плейлисты, настройки и музыка в поставку не входят.
