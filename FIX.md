# CatLu YNet 1.1.6 — импорт и экспорт плейлистов

## Изменения

- В настройках добавлены импорт и экспорт плейлистов в JSON.
- Экспорт открывает список плейлистов и сохраняет только выбранный. Имя файла подставляется по названию плейлиста; недопустимые символы Windows заменяются.
- Импорт добавляет плейлист отдельно, не объединяя его с существующими даже при одинаковом названии. Повторный импорт создаёт копию.
- Сохраняются названия, порядок треков, исполнители и привязки к YouTube. Поддерживаются прежние файлы библиотеки с несколькими плейлистами.
- Повреждённый JSON отклоняется. Ошибка записи не меняет текущую библиотеку; перед успешной заменой сохраняется резервная копия.
- Исправлены внутренние отступы и выравнивание надписей на кнопках настроек.

## Проверка

- 80 регрессионных проверок: выбор и отмена экспорта, отдельный импорт, имена файлов, сохранность данных и существующее поведение плеера.
- Живое воспроизведение YouTube и визуальная проверка диалогов вручную не выполнялись.

## Установка

`CatLuYNet-1.1.6-Setup.exe` — установщик Windows x64 со встроенным .NET.
`CatLuYNet-1.1.6-win-x64.zip` — portable архив.
Личные плейлисты и настройки в поставку не входят.
