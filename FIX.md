# CatLu YNet 1.1.7 — автоматическое обновление

## Изменения

- Проверка новой версии запускается вместе с плеером и повторяется каждые 24 часа.
- Если найден новый релиз с установщиком, рядом с названием появляется кликабельная ссылка с номером версии.
- По нажатию плеер загружает установщик, сохраняет библиотеку, запускает установку Windows и закрывается. Windows запросит разрешение на установку.
- При ошибке загрузки или отмене запроса Windows плеер остаётся открытым.
- Автоматическая установка использует только Windows-установщик из релиза GitHub; portable ZIP не запускается как установщик.

## Проверка

- Release-сборка и регрессионные проверки проекта.
- Скачать новый релиз и установить его вручную в этой проверке не удалось; скачивание выполняется при нажатии ссылки в приложении.
- Живое воспроизведение YouTube проверяется отдельно.

## Установка

`CatLuYNet-1.1.7-Setup.exe` — установщик Windows x64 со встроенным .NET.
`CatLuYNet-1.1.7-win-x64.zip` — portable архив.
Личные плейлисты и настройки в поставку не входят.
