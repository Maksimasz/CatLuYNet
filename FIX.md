# CatLu YNet 1.1.10 — имена MP3, метаданные и обложки

## Изменения

- Новые MP3 сохраняются как «Название трека [ID].mp3». Название сохраняет русский и иврит; недопустимые символы Windows заменяются. ID различает треки с одинаковыми названиями.
- Старые файлы с именами из ID продолжают находиться; существующие MP3 не переименовываются и не перезаписываются.
- При скачивании в MP3 записываются доступные сведения YouTube: название, исполнитель, альбом, дата, жанр, композитор, номера трека и диска, описание и обложка.
- Комментарий включает ссылки на ролик и канал, а также описание с исходными ссылками.
- Поле Windows «URL-адрес автора» содержит ссылку на ролик YouTube; оценка — 5 звёзд. Тег владельца не добавляется, владелец файла Windows не изменяется.
- При включённой цветомузыке обложка из локального MP3 показывается вместо кота, включая мини-плеер. Если обложки нет, остаётся кот.
- Обложка меняется вместе с треком и при кроссфейде, сохраняет пропорции и не блокирует MP3 на диске. Устаревшие результаты извлечения не подменяют обложку нового трека.

## Проверка

- Release-сборка без предупреждений и ошибок; 223 регрессионные проверки.
- Проверены безопасные и уникальные имена, совместимость со старыми файлами и поиск локальных MP3.
- В реальном MP3 проверены теги и встроенная обложка; URL автора и оценка проверены через свойства Windows.
- Извлечение обложки, отсутствие обложки, пропорции, устаревшие запросы и освобождение изображения проверены на тестовых MP3.
- Ручная установка и живое воспроизведение этой версии не проверены.

## Установка

`CatLuYNet-1.1.10-Setup.exe` — установщик Windows x64 со встроенным .NET.
`CatLuYNet-1.1.10-win-x64.zip` — portable архив.
Включены yt-dlp, FFmpeg и FFprobe. Личные плейлисты, настройки и музыка в поставку не входят.
