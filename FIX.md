# CatLu YNet 1.1.5 — улучшения стабильности

Релиз продолжает развитие проверенной Windows-версии без смены платформы и формата личной библиотеки.

## Изменения

- Главная форма разделена на тематические файлы: плейлисты, воспроизведение, мини-плеер, настройки и работу с YouTube. Поведение управления и хранения сохранено.
- Упрощена последовательность кроссфейда: проверка момента перехода, управление громкостью, запуск следующего потока и обработка ошибок выделены в отдельные методы.
- Проверка обновлений пропускает повреждённые элементы ответа GitHub и продолжает искать доступный установщик.
- Версия в заголовке окна теперь берётся из сборки и совпадает с номером установленной версии.
- Проверка ссылок и структуры библиотеки разделена на небольшие проверяемые шаги; сохранены атомарная запись и защита от повреждённых данных.

## Проверка

- Release-сборка Windows x64.
- `dotnet run --project tests/RegressionTests.csproj -c Release` — 56 проверок.
- Живое воспроизведение YouTube и звук проверяются отдельно на компьютере пользователя.

## Установка

`CatLuYNet-1.1.5-Setup.exe` — установщик Windows x64 со встроенным .NET. Личные плейлисты и настройки в установщик не включаются. Также будет доступен portable архив `CatLuYNet-1.1.5-win-x64.zip`.
