# Разработка CatLu YNet

[Описание приложения](../README.md)

## Запуск из исходников

Нужны Windows, .NET 8 SDK и бинарники `tools/yt-dlp.exe`, `tools/ffmpeg.exe`, `tools/ffprobe.exe`. FFmpeg и FFprobe в Git не хранятся: поместите их в `tools` из установленной сборки FFmpeg.

```powershell
dotnet run --project YouTubeRadio.csproj
```

Аудиопоток извлекается через yt-dlp и воспроизводится LibVLC. Параметры конвертации описаны в [документации yt-dlp](https://github.com/yt-dlp/yt-dlp#post-processing-options). Для некоторых видео набор доступных форматов может быть ограничен без поддерживаемого JavaScript runtime.

## Данные и импорт

Экспорт записывает только выбранный плейлист. Импорт сразу сохраняет библиотеку, не изменяя остальные плейлисты. Названия, порядок треков и привязки к YouTube сохраняются. Совпадающие названия не объединяются: повторный импорт добавляет копию. Старые JSON с несколькими плейлистами также поддерживаются; каждый добавляется отдельно. Аудиофайлы в экспорт не входят.

Библиотека и настройки заменяются атомарно, предыдущая версия остаётся в `.bak`. Если библиотеку не удалось прочитать, её перезапись блокируется, а причина отображается в строке состояния.

## Проверки

```powershell
dotnet run --project tests\RegressionTests.csproj
```

Проверки используют временные файлы, экземпляры форм и локальные дочерние процессы. Они не меняют личные плейлисты и не обращаются к YouTube. Проверяются сохранение данных, импорт и экспорт, очередь, отмена, пауза и кроссфейд, ссылки, формат времени, локальные MP3 и размещение кнопок. Они не заменяют проверку живого воспроизведения и ручной установки.

Проверка обновления файлов установщиком (нужен Inno Setup 7):

```powershell
.\tests\Installer.Tests.ps1
```

Она запускает небольшой тестовый установщик без прав администратора, реестра и ярлыков, только внутри `.test-temp`. Проверяет пропуск одинаковых файлов, замену изменённых, восстановление отсутствующих, полную переустановку и сохранность постороннего файла данных.

## Сборка установщика

Нужен Inno Setup 7. Версия установщика берётся из `YouTubeRadio.csproj` автоматически.

```powershell
$version = ([xml](Get-Content YouTubeRadio.csproj)).Project.PropertyGroup.Version
dotnet publish YouTubeRadio.csproj -c Release -r win-x64 --self-contained true -o "publish\win-x64-$version"
.\installer\Build-Installer.ps1
```

Установщик появится в `installer/Output`. Для portable ZIP упакуйте содержимое каталога публикации целиком. Личные JSON, настройки и музыка не должны входить в поставку.

При обнаружении установленной программы мастер показывает установленную и входящую версии и предлагает обновление либо полную установку. Обновление сравнивает SHA-256 и пропускает неизменившиеся файлы; отсутствующие и повреждённые восстанавливает. Полная установка заменяет весь комплект файлов программы в прежней папке. Установка поверх более новой версии блокируется. Для той же версии доступны восстановление изменений и полная переустановка.

После выбора режима плеер штатно закрывается с сохранением данных. Если он не закрывается, установка останавливается; принудительного завершения процесса нет. Перед копированием проверка закрытия повторяется. Плейлисты, настройки, музыка и посторонние файлы не удаляются. Установщик содержит полный комплект файлов: экономится перезапись на диске, а не размер скачивания.

Скрипт сборки создаёт временный список файлов с контрольными суммами и удаляет его после компиляции. Для нестандартного каталога публикации или компилятора доступны параметры `-PublishDirectory` и `-Compiler`. Компиляция `.iss` напрямую не поддерживается.

## Публикация

GitHub Actions загружает FFmpeg Essentials с gyan.dev, сверяет SHA-256 и подготавливает `tools/ffmpeg.exe` и `tools/ffprobe.exe` до проверок и публикации. Изменение версии в `YouTubeRadio.csproj` в ветке `main`, тег `v*` либо ручной запуск workflow собирают установщик и portable ZIP. После успешных проверок workflow создаёт релиз и тег соответствующей версии.

После загрузки установщика и ZIP проверьте версии, размеры и контрольные суммы файлов и только затем публикуйте релиз. Исходный код приложения — [MIT](../LICENSE); сторонние компоненты имеют собственные лицензии.
