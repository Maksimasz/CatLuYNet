**Музыка с YouTube и локальные MP3 в одном плеере для Windows.**

CatLu YNet воспроизводит аудио из роликов и плейлистов YouTube без видео и браузера. Создавайте собственные плейлисты и по желанию сохраняйте музыку на диск.

## Скачать

**[Последняя версия: установщик и portable ZIP](https://github.com/Maksimasz/CatLuYNet/releases/latest)**

- Требуется Windows x64. Готовые сборки включают .NET и инструменты для MP3.
- Для установки скачайте файл `CatLuYNet-…-Setup.exe` и запустите его.
- Для portable-версии распакуйте весь ZIP и запустите `YouTubeRadio.exe`. Сохраняйте структуру папок архива.

## Возможности

- Добавление отдельных роликов и целых плейлистов YouTube.
- Собственные плейлисты: переименование, добавление, удаление и изменение порядка треков.
- Независимый импорт и экспорт выбранного плейлиста в JSON.
- Необязательное скачивание выбранного трека или всего плейлиста в MP3.
- Выбор папки и качества MP3; по умолчанию — наилучшее VBR.
- Приоритет локального файла при воспроизведении и кроссфейде. Если файла нет, используется YouTube.
- Имена новых MP3 включают название трека; доступные метаданные, ссылки и обложка записываются внутрь файла. В свойствах Windows — ссылка на YouTube и оценка 5 звёзд.
- При цветомузыке обложка локального MP3 показывается вместо кота; без обложки остаётся кот.
- Предыдущий трек, воспроизведение, пауза, стоп, следующий трек и громкость.
- Темы оформления, русский, английский, иврит и литовский языки, часы, информация о треке и мини-плеер.
- Проверка обновлений при запуске и каждые 24 часа.

## Как пользоваться

1. Вставьте ссылку YouTube в верхнее поле и сохраните её. Для отдельного ролика выберите свой плейлист, для нового YouTube-плейлиста задайте название.
2. Нажмите на трек для воспроизведения. Кнопка `✎` открывает редактор плейлиста, `⚙` — настройки.
3. Для локальной копии включите «Скачать MP3» при добавлении или воспользуйтесь кнопками скачивания в редакторе.
4. Выберите место сохранения: внутри него создаётся папка с названием плейлиста. Полный путь виден в окне скачивания; выбранное место запоминается.
5. Настройте качество MP3 через `⚙`. Доступны наилучшее VBR, 320, 256, 192 и 128 кбит/с.

Уже скачанные файлы не перезаписываются. Новое качество применяется к новым скачиваниям; качество исходника YouTube ограничивает результат. При отмене готовые MP3 сохраняются. Для YouTube и скачивания нужен интернет; сохранённый MP3 можно слушать без подключения. Недоступные ролики скачать нельзя.

## Плейлисты и данные

В настройках экспортируйте один выбранный плейлист в JSON. Импорт добавляет его отдельно, не объединяя списки с одинаковыми названиями. Аудиофайлы в JSON не входят. Ссылка с `v=…` добавляется как один ролик, даже если содержит `list` и `index`.

Данные хранятся в `%LOCALAPPDATA%\CatLuYNet`. Рядом с файлами библиотеки и настроек сохраняются резервные копии `.bak`. Удаление трека из плейлиста не удаляет скачанный MP3 с диска.
