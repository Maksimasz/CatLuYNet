# CatLu YNet

CatLu YNet — настольный аудиоплеер для прослушивания роликов и плейлистов YouTube без видео.

## Возможности

- добавление отдельного ролика или целого плейлиста YouTube;
- личные плейлисты: редактирование, переименование, изменение порядка и удаление;
- аудиопоток через `yt-dlp` и LibVLC без браузера;
- пять кнопок управления: предыдущий, воспроизведение, пауза, стоп, следующий;
- кроссфейд, выравнивание громкости, темы, языки, часы и информация о треке;
- локальное хранение плейлистов и настроек в `%LOCALAPPDATA%\CatLuYNet`.

## Запуск из исходного кода

Требуются Windows и .NET 8 SDK.

```powershell
dotnet run --project YouTubeRadio.csproj
```

## Как пользоваться

1. Вставьте ссылку YouTube в верхнее поле.
2. Для отдельного ролика выберите личный плейлист.
3. Для ссылки только с `list=...` укажите название нового плейлиста.
4. Откройте плейлист кнопкой `✎`, чтобы переименовать его, добавить ролик, изменить порядок или удалить.
5. Нажмите `⚙` для глобальных настроек.

В настройках кнопка «Экспорт плейлистов» открывает список: выберите один плейлист, нажмите «Экспорт плейлистов» и укажите файл JSON. В файл попадёт только выбранный плейлист. «Импорт плейлистов» добавляет его отдельным плейлистом и сразу сохраняет библиотеку, не меняя остальные. Названия, порядок треков и привязки к YouTube сохраняются. Совпадающие названия не объединяются: повторный импорт добавит ещё одну копию. Старые файлы с несколькими плейлистами тоже поддерживаются — каждый добавляется отдельно. Аудиофайлы в экспорт не входят.

Ссылка с `v=...` добавляется как один ролик, даже если содержит параметры `list` и `index`.

При сохранении библиотека и настройки заменяются атомарно; предыдущая версия остаётся в файле `.bak` рядом с основным JSON. Если библиотеку не удалось прочитать, её перезапись блокируется, а причина отображается в строке состояния.

## Проверка исправлений

```powershell
dotnet run --project tests\RegressionTests.csproj
```

Проверки используют временную папку, скрытые экземпляры формы и локальные дочерние процессы. Они не изменяют личные плейлисты и не обращаются к YouTube. Проверяются сохранение и восстановимость данных, очередь, отмена, состояние паузы и кроссфейда, освобождение карточек, ссылки и формат времени. Живое воспроизведение YouTube проверяется отдельно.

## Сборка установщика

```powershell
dotnet publish YouTubeRadio.csproj -c Release -r win-x64 --self-contained true -o publish\win-x64-1.1.7
& 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' installer\CatLuYNet.iss
```

Готовый установщик появится в `installer\Output`.
Публикация тега вида `v1.1.7` автоматически собирает установщик и portable ZIP в GitHub Actions и прикрепляет их к релизу.

### Локальные MP3

При добавлении ссылки включите «Скачать MP3», если нужна локальная копия. В редакторе плейлиста доступны «Скачать выбранный MP3» и «Скачать все MP3». Папка и качество задаются в настройках; по умолчанию — Музыка/CatLu YNet и наилучшее VBR. Это качество перекодирования MP3, ограниченное качеством исходника YouTube.

При воспроизведении, включая кроссфейд, найденный локальный файл имеет приоритет. Если файл отсутствует, используется YouTube. В списке показано наличие MP3. Удаление трека из плейлиста не удаляет файл. Уже сохранённые файлы не перезаписываются; настройка качества применяется к новым скачиваниям. Имена файлов — ID видео, поэтому переименование трека не нарушает связь. Отмена сохраняет завершённые MP3 и убирает временные файлы текущего скачивания.

Для сборки нужны `tools/ffmpeg.exe` и `tools/ffprobe.exe` из установленного FFmpeg (рядом с `yt-dlp.exe`). Бинарники FFmpeg не хранятся в Git; workflow подготавливает их перед упаковкой. На этом компьютере использована установленная сборка Gyan FFmpeg. Документация параметров MP3: https://github.com/yt-dlp/yt-dlp#post-processing-options.

Перед скачиванием открывается выбор места. В выбранной папке создаётся подпапка с названием плейлиста; полный путь виден в окне скачивания. Выбранное место запоминается в настройках. Недопустимые символы названия заменяются, уже сохранённые файлы не перемещаются.
