# CatLu YNet

CatLu YNet — настольный аудиоплеер для прослушивания роликов и плейлистов YouTube без видео.

## Возможности

- добавление отдельного ролика или целого плейлиста YouTube;
- личные плейлисты: редактирование, переименование, изменение порядка и удаление;
- аудиопоток через `yt-dlp` и LibVLC без браузера;
- пять кнопок управления: предыдущий, воспроизведение, пауза, стоп, следующий;
- кроссфейд, выравнивание громкости, темы, языки, часы и информация о треке;
- локальное хранение плейлистов и настроек в `%LOCALAPPDATA%\CatLuYNet`.

## Запуск из исходного кода

Требуются Windows и .NET 8 SDK.

```powershell
dotnet run --project YouTubeRadio.csproj
```

## Как пользоваться

1. Вставьте ссылку YouTube в верхнее поле.
2. Для отдельного ролика выберите личный плейлист.
3. Для ссылки только с `list=...` укажите название нового плейлиста.
4. Откройте плейлист кнопкой `✎`, чтобы переименовать его, добавить ролик, изменить порядок или удалить.
5. Нажмите `⚙` для глобальных настроек.

Ссылка с `v=...` добавляется как один ролик, даже если содержит параметры `list` и `index`.

## Сборка установщика

```powershell
dotnet publish YouTubeRadio.csproj -c Release -r win-x64 --self-contained true -o publish\win-x64
& 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' installer\CatLuYNet.iss
```

Готовый установщик появится в `installer\Output`.
